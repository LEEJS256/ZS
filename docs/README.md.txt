# Project Overview

## 개요
- 타워설치 슈팅 멀티플레이 디펜스 게임
- GAS 기반 전투 시스템

## 핵심 시스템
- Gameplay Ability System 기반 데미지 처리
- 캐릭터의 스킬과 각종 타워설치를 통한 몬스터 디펜스 게임
- 투사체 기반 전투
- 복잡한 인벤토리

## 주요 기능
- Projectile 기반 공격
- 몬스터 데미지 처리
- 데미지 UI 출력
